# Architecture Design

Below is a text-based representation of the file tree.
```bash
src
  ├── main
  │   └── java
  │       └── org
  │           └── mdkt
  │               └── compiler
  │                   ├── CompilationException.java
  │                   ├── CompiledCode.java
  │                   ├── DynamicClassLoader.java
  │                   ├── ExtendedStandardJavaFileManager.java
  │                   ├── InMemoryJavaCompiler.java
  │                   └── SourceCode.java

```

`CompilationException.java` :

- `CompilationException(String msg)`: A custom runtime exception class used to represent errors that occur during source code compilation.

  - Inherits from `RuntimeException` and includes a standard constructor that accepts an error message string.
  - Contains a fixed `serialVersionUID` for serialization compatibility.

`CompiledCode.java` :

- `CompiledCode(className: str)`: A class that extends `SimpleJavaFileObject` to represent compiled Java bytecode in memory. It is used during in-memory compilation to capture the output of the Java compiler as a byte array.

  - `getClassName() -> str`: Returns the fully qualified name of the compiled class.
  - `openOutputStream() -> OutputStream`: Overrides the parent method to provide an output stream (a `ByteArrayOutputStream`) where the compiler writes the generated bytecode.
  - `getByteCode() -> bytes`: Returns the compiled bytecode as a byte array, captured from the internal `ByteArrayOutputStream`.

`DynamicClassLoader.java` :

- `DynamicClassLoader(ClassLoader parent)`: A custom class loader that extends `ClassLoader` to support dynamic loading of compiled Java classes at runtime. It stores compiled code in an internal map and overrides the class-finding mechanism to load these classes on demand.

  - `addCode(CompiledCode cc)`: Registers a `CompiledCode` object (representing dynamically compiled Java bytecode) under its fully qualified class name for later loading by this class loader.
  
  - `findClass(String name)`: Overrides the default class-finding behavior to first check the internal map of compiled classes; if found, it defines and returns the class from the stored bytecode, otherwise delegates to the parent class loader.

  `ExtendedStandardJavaFileManager.java` :

- `ExtendedStandardJavaFileManager(JavaFileManager fileManager, DynamicClassLoader cl)`: A custom Java file manager that extends `ForwardingJavaFileManager` to support in-memory compilation of multiple Java source units by capturing compiled bytecode.

  - `getJavaFileForOutput(JavaFileManager.Location location, String className, JavaFileObject.Kind kind, FileObject sibling)`: Overrides the standard method to intercept output files during compilation; creates and registers a `CompiledCode` object for each generated class, enabling in-memory storage of compiled bytecode.
  
  - `getClassLoader(JavaFileManager.Location location)`: Returns the provided `DynamicClassLoader` instance, ensuring that dynamically compiled classes can be loaded at runtime.

  - The instance attribute `compiledCode` is a list storing all `CompiledCode` objects generated during compilation.
  - The instance attribute `cl` holds the `DynamicClassLoader` used to load dynamically compiled classes.

`InMemoryJavaCompiler.java` :

- `InMemoryJavaCompiler.newInstance()`: Creates and returns a new instance of the in-memory Java compiler using default settings.

- `InMemoryJavaCompiler`: A class that enables compiling Java source code in memory without writing files to disk. It uses the standard Java Compiler API and supports dynamic class loading.

  - `useParentClassLoader(ClassLoader parent)`: Sets the parent class loader used for dynamically loading compiled classes; returns the current compiler instance for method chaining.
  
  - `getClassloader()`: Returns the internal dynamic class loader used to load compiled classes.
  
  - `useOptions(String... options)`: Configures compiler options (e.g., `-Xlint:unchecked`) to be passed during compilation; returns the current compiler instance.
  
  - `ignoreWarnings()`: Enables suppression of non-critical compiler warnings (e.g., unchecked operations); returns the current compiler instance.
  
  - `compileAll() -> Map<String, Class<?>>`: Compiles all previously added source codes and returns a map of fully qualified class names to their corresponding loaded `Class` objects. Throws a `CompilationException` if compilation fails or if warnings are not ignored and present.
  
  - `compile(String className, String sourceCode) -> Class<?>`: Compiles a single Java source string with the given class name and returns the resulting `Class` object. Internally adds the source and invokes `compileAll()`.
  
  - `addSource(String className, String sourceCode) -> InMemoryJavaCompiler`: Registers a Java source code string under the specified class name for later compilation; returns the current compiler instance for method chaining.

`SourceCode.java` :

- `SourceCode(className: str, contents: str)`: A class representing in-memory Java source code as a `SimpleJavaFileObject`, used primarily for dynamic compilation. It constructs a virtual URI for the source and stores the class name and source content.

  - `getClassName() -> str`: Returns the fully qualified class name associated with this source code object.
  
  - `getCharContent(ignoreEncodingErrors: bool) -> CharSequence`: Returns the source code content as a character sequence; required by the `SimpleJavaFileObject` contract for compiler tools to read the source.
