# Product Requirements Document: Java-Emoji-Conventer

## Introduction

**Java Emoji Converter** is an emoji conversion tool designed to facilitate the transformation of emoji strings between various formats and specifications. The project provides a utility that enables developers to convert emoji characters generated by different client platforms into alternative representations, including Softbank emoji, Unicode emoji, alias emoji, and HTML emoji formats.  

## Goals

The primary goal of this project is to provide a comprehensive solution for handling emoji compatibility across different systems and platforms. By offering seamless conversion between multiple emoji formats, the tool aims to solve interoperability challenges that arise when emoji strings need to be shared or displayed across various client specifications and environments. The project leverages standardized emoji data sources to ensure accurate conversions between different emoji representations.  

## Features and Functionalities

The following features and functionalities are provided by the java-emoji-converter project:

### Emoji Format Conversion

- Ability to convert emoji strings from Unicode format to alias format (e.g., 😃 → `:smiley:`)  

- Ability to convert emoji strings from Unicode format to HTML decimal entities (e.g., 😃 → `&#128515;`)  

- Ability to convert emoji strings from alias format to Unicode format (e.g., `:smiley:` → 😃)  

- Ability to handle mixed emoji formats in a single string with automatic detection and conversion  

### SoftBank Emoji Support

- Ability to automatically detect SoftBank emoji characters in input strings  

- Ability to convert SoftBank emoji format to Unicode format using emoji4unicode mapping data  

- Ability to handle both single-character and multi-character SoftBank emoji sequences  

- Ability to process SoftBank emoji codes from the complete SoftBank emoji character set (0xe001-0xe537)  

### Emoji Mapping Data Management

- Ability to load emoji mapping data from remote URL (Google's emoji4unicode XML data)  

- Ability to fallback to local emoji mapping data when remote loading fails  

- Ability to parse and build SoftBank-to-Unicode mapping tables from emoji4unicode XML format  

- Ability to support multiple emoji vendor formats including DoCoMo, Google, KDDI, and SoftBank  

### Architecture and Design

- Ability to use singleton pattern for the `EmojiConverter` instance to ensure efficient resource usage  

- Ability to lazy-load emoji mapping data only when SoftBank emoji conversion is needed  

- Ability to handle Unicode code point arrays for proper multi-byte character processing

## Usage

### Maven Dependency

Add this dependency to your Maven `pom.xml`:

```xml
<dependency>
  <groupId>com.github.binarywang</groupId>
  <artifactId>java-emoji-converter</artifactId>
  <version>1.0.2</version>
</dependency>
```  

### Basic Conversion

First, get the singleton instance of `EmojiConverter`:

```java
private EmojiConverter emojiConverter = EmojiConverter.getInstance();
```  

### Conversion Methods

#### Convert Unicode/Softbank Emoji to Aliases

Converts emoji characters to their alias format (e.g., `:smiley:`):

```java
String str = "  An 😃😀awesome 😃😃string with a few 😃😉emojis!";
String alias = emojiConverter.toAlias(str);
// Result: ":no_good: :ok_woman: :couple_with_heart:An :smiley::grinning:awesome :smiley::smiley:string with a few :smiley::wink:emojis!"
```  

#### Convert Unicode/Softbank Emoji to HTML

Converts emoji characters to HTML decimal entities:

```java
String str = "  An 😀😃awesome 😃😃string with a few 😉😃emojis!";
String result = emojiConverter.toHtml(str);
// Result: "&#128581; &#128582; &#128145;An &#128512;&#128515;awesome &#128515;&#128515;string with a few &#128521;&#128515;emojis!"
```  

#### Convert Aliases to Unicode Emoji

Converts alias format to Unicode emoji characters:

```java
String str = "   :smiley: :grinning: :wink:";
String result = emojiConverter.toUnicode(str);
// Result: "🙅 🙆 💑 😃 😀 😉"
```  

## Terms/Concepts Explanation

**Unicode Emoji**: Modern UTF-8 emoji characters (e.g., 😃, 😀, 😉) that are the standard representation of emojis across modern applications and databases. These are the native emoji format supported by contemporary systems.  

**SoftBank Emoji**: A legacy proprietary emoji encoding format used on Japanese SoftBank mobile phones before Unicode emoji standardization. These emojis are stored as hexadecimal character codes in the private use area (e.g., `0xE04A`, `0xE049`) and require conversion to Unicode for modern compatibility.  

**Alias Format**: Text-based emoji shortcodes enclosed in colons (e.g., `:smiley:`, `:grinning:`, `:wink:`), commonly used in chat platforms, Markdown documents, and GitHub-flavored markdown for human-readable emoji representation.  

**HTML Decimal Entity**: HTML-encoded emoji representation using numeric character references (e.g., `&#128515;`, `&#128512;`, `&#128521;`), used in web pages and email templates where direct Unicode characters may not render correctly.  

**emoji4unicode.xml**: An XML data file maintained by Google's emoji4unicode project that contains historical mappings between different emoji encoding systems, including attributes for SoftBank (`softbank`), Unicode (`unicode`), DoCoMo (`docomo`), KDDI (`kddi`), and Google (`google`) carrier codes.  

**Code Point**: The numeric value that represents a character in Unicode. The library uses code points to perform character-level operations during SoftBank-to-Unicode conversion, as some characters may require multiple code points.  

**Two-Codepoint Lookahead Algorithm**: A conversion technique that attempts to match two consecutive SoftBank characters first (as some SoftBank emojis use two characters), then falls back to single-character matching if no two-character match is found. This ensures correct handling of multi-character emoji sequences.  

**Singleton Pattern**: A design pattern that ensures only one instance of the `EmojiConverter` class exists throughout the application lifecycle, accessed via `getInstance()`, which provides thread-safe access to conversion methods.  

**Emoji Mapping Table**: A `Map<List<Integer>, String>` data structure that stores the conversion mappings from SoftBank code points (as lists of integers) to Unicode emoji strings, built by parsing the emoji4unicode.xml file.  

**XStream**: An XML serialization library used to parse the emoji4unicode.xml file and deserialize it into Java objects representing emoji data structures with categories, subcategories, and element attributes.  

**emoji-java Library**: An external dependency (version 5.1.1) that provides standard emoji parsing capabilities through `EmojiParser` methods (`parseToAliases()`, `parseToHtmlDecimal()`, `parseToUnicode()`), which handle modern Unicode-to-alias and alias-to-Unicode conversions.  

**SoftBank Character Set**: A pre-computed immutable set containing 471 SoftBank emoji character codes, used by `containsSbEmoji()` for efficient O(1) detection of whether an input string contains legacy SoftBank emojis requiring conversion.  

**Idempotent Conversion**: A defensive programming technique where the library performs a second conversion pass and compares results to ensure the output is stable (i.e., converting the output again produces the same result), handling edge cases with mixed or nested emoji formats.  

**Lazy Initialization**: A resource optimization strategy where the `EmojiReader` instance is only created when SoftBank emoji conversion is first needed, rather than during converter initialization, reducing startup overhead when SoftBank conversion is not required.
